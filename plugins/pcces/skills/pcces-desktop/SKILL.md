# 用電腦控制操作 PCCES

| 你要做的／碰到的 | 去哪一節 | 速答 |
| --- | --- | --- |
| 開始操作之前 | 先讓 PCCES 以一般權限執行 | 先徵得使用者同意（電腦控制會接管滑鼠鍵盤），再跑這支 skill 資料夾裡的 `啟動PCCES給電腦控制.ps1`，結束碼 0 才往下 |
| 點了沒反應、按鈕會亮但不動作 | 先讓 PCCES 以一般權限執行 | PCCES 是高權限，UIPI 擋掉點擊；請使用者關掉 PCCES 再跑啟動腳本 |
| 匯出預算書 XML | 匯出電子標單 | 檔案 → 製作電子檔及列印報表，勾 xml（要完整再勾 zmd） |
| 中途跳出的詢問 | 各對話框怎麼回 | 只匯出就不重新總計、不做自主檢查，不改動預算書資料 |

標記體例：`✅` 實測過、`⚠️` 已知限制、`📌` 未查證。沒掛標記＝一般說明，不涉及事實宣稱。

## 先讓 PCCES 以一般權限執行

PCCES 的 manifest 要求系統管理員權限，照常啟動就是高完整性，而電腦控制是一般權限，Windows 的 UIPI 會擋掉它送的點擊與按鍵。

1. 動手前先跟使用者說清楚：電腦控制會接管滑鼠和鍵盤，操作期間他不能用這台電腦，也不要自己點 PCCES；他明確同意了才啟動。
2. 從一般權限的 shell 跑 `powershell -NoProfile -ExecutionPolicy Bypass -File "${CLAUDE_SKILL_DIR}\啟動PCCES給電腦控制.ps1"`（`${CLAUDE_SKILL_DIR}` 就是載入這支 skill 時開頭寫的 Base directory；使用者也可以自己雙擊同一個資料夾的 `Start-PCCES-for-Claude.bat`）。
   1. 結束碼 0：PCCES 已是一般權限，可以操作。
   2. 結束碼 1：照腳本印的訊息請使用者處理，多半是已有高權限的 PCCES 在跑，要他整個關掉。
   3. 結束碼 2：找不到安裝位置，問使用者 PCCES 裝在哪。
3. ✅ 從「終端機（系統管理員）」設 `RunAsInvoker` 再啟動沒有用，新行程會繼承高權限。
4. 不要用 `open_application` 把 PCCES 叫到前面：它會再執行一次 `PccesMain.exe`。PCCES 不在前面時，請使用者點一下它的視窗。

## 登入

✅ 啟動後先跳「使用者登入」，帳號 `PCCES`、密碼空白，直接按「確定」。接著問要不要註冊，選「否」。

## 匯出電子標單

1. 首頁點「預算書編製」，在專案挑選清單雙擊要匯出的工程。
2. 選單「檔案 → 製作電子檔及列印報表」，格式選「預算書」，按「下一步」。
3. 格式勾「工程會電子標單檔 xml 格式」；要完整資料另勾「工程會 PCCES 內部交換格式（zmd）」，zmd 其實是內含 `.mdb` 的 zip。
4. 存放路徑改成使用者指定的資料夾（先問他要放哪，例如「文件」底下）。⚠️ 這個欄位按 `ctrl+a` 不會全選：先按 `End` 再按 `shift+Home`、`Delete` 清空，再輸入路徑，最後按 `Home`／`End` 放大確認前後兩段都對。⚠️ 中文路徑是經剪貼簿貼上的，兩次實測各有一次貼成剪貼簿裡的舊內容（另一個網址或路徑）；不對就再清空重打一次，不要直接按下一步。
5. 一路「下一步」到「恭喜您」，按「完成」。檔名會是 `(預算書)<工程名稱><工程代碼>_ap_bdgt.xml`。

## 各對話框怎麼回

| 對話框 | 回答 | 原因 |
| --- | --- | --- |
| 偵測到資料有異動，建議先重新總計，是否結束電子檔製作 | 否 | 選「是」會結束匯出；重新總計會改動預算書資料，只匯出不需要 |
| 尚未完全勾選自主檢查 | 我有把握不需檢查，繼續 | 自主檢查是送件前的檢核，匯出看結構用不到 |
| XML 格式有異動，請確認對方使用 4.3.1000.81 以後版本 | 確定 | 只是提醒 |

## 不做的事

1. 不刪專案。改預算書內容、按「重新總計」只在使用者交辦時做，而且只動匯入的那一筆工程，不碰原案。
2. ⚠️ 一般權限下 PCCES 寫不進 `Program Files` 裡的 log。開預算書、匯入、改值、重新總計、匯出都實測正常；出錯時先改回讓使用者以系統管理員身分自己操作。

## 匯入 XML、改值、重新總計

1. 匯入：專案目錄 → 專案建立‧轉入 → XML 電子檔轉入 → 瀏覽。✅ 檔名欄 `ctrl+v` 不一定貼得上，用 type 直接輸入不含中文的路徑（檔案在中文路徑時先複製到不含中文的資料夾，例如 `%TEMP%\pcces\`）。非 PCCES 製作的檔會跳兩個警告，按確定照樣匯入；工程代碼重複自動加 `-01`。
2. 開預算書：左欄「預算書編製」→ 雙擊工程。雙擊後挑選清單可能再跳一次，按取消；打開後先按 `Escape`，免得游標停在某格的編輯狀態。
3. 改值：點數量或單價格 → `ctrl+a` → type 新值 → `Enter`。✅ 三千多列的預算書按 Enter 後視窗無回應約 80 秒，用 `Get-Process PccesMain` 的 `Responding` 等它回來再截圖，不要中途點擊。
4. 重新總計：工具列「重新總計」→ 是 → 完成；之後依序跳幾個警告（分析子項數量為 0、複價為 0、工項名稱重複）按確定，「是否顯示複價為 0 明細」按否。
5. 畫面底部的總計會晚一步更新；數字以資料庫 `budProject.projamt` 為準（資料庫工具只發 SELECT）。
6. 改單價分析：在詳細表那一列按右鍵 →「單價分析」，開出組成視窗；改數量或單價同樣是點格、`ctrl+a`、type、`Enter`。⚠️ 在分析視窗按 `Escape` 會直接關掉視窗，要離開格子改點別格；改完按工具列「重新小計」看分析單價，再按右下「結束」。
7. ✅ 一般工料（不是變動單價）的單價全案共用：只在一個分析裡改，重新總計後所有用到它的分析與資源統計都跟著變。
8. ⚠️ 雙擊開預算書有時跳「系統偵測出問題，請重新開啟」，PCCES 原檔匯入的工程也會；按確定後預算書照常開啟。
